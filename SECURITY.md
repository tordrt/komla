# Security Policy

## Reporting a vulnerability

Please report vulnerabilities privately, not in a public issue:

- [Report a vulnerability](https://github.com/tordrt/komla/security/advisories/new) on GitHub, or
- write to us through [komla.dev/contact](https://komla.dev/contact).

Include what you found, how to reproduce it, and the Komla version and platform. We'll confirm we got your report within a few days and keep you updated until it's fixed.

## Supported versions

Security fixes go into the latest release. Official builds update themselves; builds from source need to be rebuilt from the latest `main`.
